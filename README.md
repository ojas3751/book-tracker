# book-tracker

シリーズ単位で新刊を追える読書管理Webアプリです。

既存の読書管理サービスの新刊通知は著者をフォローする形のものが多く、興味のない作品まで拾ってしまいます。このアプリでは追う単位をシリーズ（作品）にし、ボタンを押したときだけ、対象のシリーズの新刊を検索します。

## 主な機能（予定）

- **本の登録**：タイトル・著者・ISBNで外部APIを検索し、結果から選んで登録する
- **本棚**：登録した本をシリーズごとにまとめて表示する。グリッドとリストを切り替えられ、テキスト・タグ・状態で絞り込める
- **ステータス管理**：読書状態、購入状況（媒体・購入場所）、評価（星5つ、0.5刻み）、メモ、タグ
- **新刊検索**：シリーズ単位、または追跡中のシリーズを一括で検索し、新刊・未所持の既刊・別版に分けて候補を表示する。関係ない候補は「対象外」にできる

対象とする本はマンガ、ライトノベル、一般書（単行本・文庫・新書）です。
