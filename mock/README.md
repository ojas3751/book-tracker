# UI確認用のモック

画面の作りを比べて決めるためのモックです。HTML と JavaScript だけで動き、サーバーは要りません。

## 開き方

1. `mock/index.html` をブラウザで開く（ダブルクリックでよい）
2. ID・パスワードとも `admin` でログインする（見せかけのログインです）

スマホの見た目は、ブラウザの開発者ツールで幅を 360〜412px にして確認します。

## 範囲

- 画面：ログイン → 本棚 → シリーズページ → ブックページ
- 本の登録、新刊候補、設定の画面は対象外です（メニューから開くと、その旨を表示します）

## ページの開き方

2つの案を比べ、B案に決めました（要件定義書 4.7）。モックには B案だけを残しています。

- シリーズページ・ブックページは、PCでは一覧の右にパネル、スマホでは下から出るボトムシートで開く
- 本棚の絞り込みは、［絞り込み］ボタンで開く別のパネルで選ぶ

ボトムシートは、上の取っ手を上に引くと全画面、下に引くと閉じます。ブラウザの戻る操作でも、重ねたページが閉じます。

## 注意

- データはすべてダミーです（`data.js`）。作品名は実在のものですが、巻数・発売日・ISBN・ステータスは実際のものではありません
- 表紙はダミーで、色とタイトルだけを描いています
- 編集や削除は、ページを開いている間だけ反映されます。再読み込みすると元に戻ります
- グリッドとリスト、巻の並び、新刊候補を畳んでいるかどうかはブラウザに保存されます
