# UI確認用のモック

画面の作りを比べて決めるためのモックです。HTML と JavaScript だけで動き、サーバーは要りません。

## 開き方

1. `mock/index.html` をブラウザで開く（ダブルクリックでよい）
2. ID・パスワードとも `admin` でログインする（見せかけのログインです）

スマホの見た目は、ブラウザの開発者ツールで幅を 360〜412px にして確認します。

## 範囲

- 作った画面：ログイン、本棚、シリーズページ、ブックページ、本の登録
- まだ作っていない画面：新刊候補、設定（メニューから開くと、その旨を表示します）

## 本の登録

- 外部APIの代わりに、`data.js` のダミーの書誌データから探します。登録済みの本のほか、検索でだけ見つかる本（「ワンパンマン」「薬屋のひとりごと」のコミック版など）も入れてあります
- 検索結果は 30 件ずつ取得し（楽天APIの1回分にあたる）、表示は本棚と同じように少しずつ増やします
- シリーズページ・ブックページの［＋］から開くと、そのシリーズと巻数を初期値にし、登録が終わるとシリーズページに戻ります
- 「見つからないときは手で入力」から、書誌情報を手で入力して登録できます。表紙の画像は、ページを開いている間だけ表示します
- 手で入力した本の書誌情報をブックページで直す機能（要件定義書 3.1）は、モックでは作っていません。本番の実装で対応します

## ページの開き方

2つの案を比べ、B案に決めました（要件定義書 4.7）。モックには B案だけを残しています。

- シリーズページ・ブックページは、PCでは一覧の右にパネル、スマホでは下から出るボトムシートで開く
- 本棚の絞り込みは、［絞り込み］ボタンで開く別のパネルで選ぶ

ボトムシートは、上の取っ手を上に引くと全画面、下に引くと閉じます。ブラウザの戻る操作でも、重ねたページが閉じます。

## 注意

- データはすべてダミーです（`data.js`）。作品名は実在のものですが、巻数・発売日・ISBN・ステータスは実際のものではありません
- 表紙はダミーで、色とタイトルだけを描いています
- 登録・編集・削除は、ページを開いている間だけ反映されます。再読み込みすると元に戻ります
- グリッドとリスト、巻の並び、新刊候補を畳んでいるかどうか、表示の色はブラウザに保存されます
